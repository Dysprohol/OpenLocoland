SAVING AND PLAYING

CTRL+S SAVES THE MAP. A NEW MAP, POLIGON
AND THE TEMPLATE (AN UPDATE WRITES THEM
AGAIN) ASK FOR A NAME OF THEIR OWN, GET A
FOLDER IN MAPS AND ARE ON CUSTOM MAPS.
MENU: NEW MAP, LOAD, SAVE (UNDER A NEW
NAME), EXPORT AND IMPORT (A .ZIP FILE),
MISSION SETTINGS, MAP SIZE, PLAY, UNDO,
REDO, RUN THE LEVEL, BACK TO THE MENU.
PLAY THE MAP STARTS IT AS A MISSION, THEN
THE EDITOR COMES BACK. RUN THE LEVEL
(CTRL+R) LETS IT RUN HERE, CTRL+R STOPS
IT. UNSAVED CHANGES ARE ASKED FOR FIRST.
