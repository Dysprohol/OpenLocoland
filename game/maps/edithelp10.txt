SAVING AND PLAYING

CTRL+S SAVES THE MAP. A NEW MAP ASKS
FOR ITS NAME FIRST, GETS A FOLDER IN
MAPS AND IS LISTED ON CUSTOM MAPS.
MENU: NEW MAP, LOAD, SAVE (UNDER A NEW
NAME), EXPORT AND IMPORT (A .ZIP FILE),
MISSION SETTINGS, MAP SIZE, PLAY, UNDO,
REDO, RUN THE LEVEL, BACK TO THE MENU.
PLAY THE MAP STARTS IT AS A MISSION;
WHEN IT ENDS, THE EDITOR COMES BACK.
RUN THE LEVEL (CTRL+R) LETS IT RUN
HERE; CTRL+R AGAIN STOPS IT.
CHANGES NOT SAVED ARE ASKED FOR FIRST.
