MAP FILES

A MAP IS ITS FOLDER IN MAPS: NAME.MAP, .VID,
.LGC AND THE TEXTS, NAMED AS THE FOLDER.
CUSTOM MAPS FINDS EVERY SUCH FOLDER - SAVED,
IMPORTED, COPIED IN OR RENAMED BY HAND -
AND DROPS ONE THAT IS GONE.
MENU: RENAME OR DELETE. A NEW NAME MOVES
THE FOLDER AND RENAMES ITS FILES; DELETE
PUTS THE FOLDER IN THE RECYCLE BIN.
A NAME: UP TO 64 ENGLISH LETTERS, DIGITS,
SPACES AND THE SIGNS WINDOWS ALLOWS IN FILE
NAMES; NOT A FOLDER OF THE GAME (L01-L20,
SANDBOX, TEMPLATE, SCRIPT, OUTRO).
