THE MAP'S OWN SCRIPT

NAME.LGC: THE EDITOR WRITES ONLY ITS
BLOCKS FROM // <EDITOR>, <EDITOR MAIN>,
<EDITOR ARRIVALS>, <EDITOR TACT> TO THEIR
// </...> LINES; THE REST STAYS YOURS. A
SCRIPT WITHOUT THEM GETS THEM UNDER A NEW
NAME. TO KEEP A SCRIPT OF YOUR OWN AS IT
IS: MISSION SETTINGS, UNTICK "THE EDITOR
WRITES THE MAP'S SCRIPT" (THE SCRIPT GETS
THE LINE // <EDITOR OFF>). THEN NO SAVE,
SAVE UNDER A NEW NAME OR QUICK TEST WRITES
INTO IT; ITS SETTINGS ARE ONLY SHOWN.
