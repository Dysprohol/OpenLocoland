# Contributing to OpenLocoland

OpenLocoland is a fan project developed by one maintainer (Dysprohol) on a set plan (see "Plans" in
[README.md](README.md)). Help is welcome; this page says in what form, so that nobody puts work into
something that cannot be taken in.

## Welcome at any time

- **Bug reports, crashes, ideas** - open an [issue](https://github.com/Dysprohol/OpenLocoland/issues).
  A report is most useful with the version of OpenLocoland, the edition of the game, what was done
  and what happened, and the files of the game's `logs` folder. A map that shows the problem helps a
  lot.
- **Translations** - as described in [TRANSLATING.md](docs/TRANSLATING.md); no git is needed.
- **Small corrections** - a typo, a broken link, a wrong fact in the documentation - can come as a
  pull request straight away.

## Agreed with the maintainer first

Anything bigger - a change to the code, the editor, the tools, the documentation's structure,
artwork, video, sound - is agreed before the work starts: open an issue that says what you would
like to do and wait for an answer. A pull request that was not agreed beforehand is closed without
a review. That is no judgement of the work; one person maintains all of this, and every change
taken in has to be tested on every edition of the game and kept working afterwards.

## Tools, mods and maps of your own

Tools built around the game - editor plugins, script helpers, converters -, mods and maps stay in
their authors' own repositories, where they can be released on their own schedule. This repository
does not take them in. The [Discord server](https://discord.gg/NG5DnHFvYM) is the place to show
them.

## What the repository cannot hold

Nothing of the game itself and nothing derived from it: no game files, no unpacked data, no
decompiled code, no lists taken out of the game's scripts. The game's files come from the player's
own copy when the game is put together (see "What must not be shared" in
[docs/dev/release.md](docs/dev/release.md)).
